# Projeto RPG C++ - Proway
 
Este projeto é um jogo de RPG simples desenvolvido em C++ para fins educacionais. O jogador pode escolher entre diferentes classes de personagens (Guerreiro, Mago, Arqueiro) e enfrentar inimigos utilizando ataques e habilidades especiais.
 
## Estrutura do Projeto
 
```
trabalho-rpg-cpp-Proway/
├── arqueiro.cpp / arqueiro.h
├── guerreiro.cpp / guerreiro.h
├── habilidade.cpp / habilidade.h
├── inimigo.cpp / inimigo.h
├── mago.cpp / mago.h
├── main.cpp
├── menu.cpp / menu.h
├── personagem.cpp / personagem.h
└── output/
```
 
Siga as instruções do menu para criar seu personagem e iniciar a aventura.
 
## Funcionalidades
 
- Escolha de personagem: Guerreiro, Mago ou Arqueiro
- Sistema de combate por turnos
- Habilidades especiais para cada classe
- Sistema de coragem e covardia
- Inimigos com diferentes características
